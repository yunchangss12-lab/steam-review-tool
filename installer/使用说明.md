# Steam 差评 × 更新记录 比对归类工具 — 使用说明

## 一、快速开始

1. 双击桌面上的「Steam差评比对工具」图标启动。
2. 输入游戏的 **AppID**（游戏商店页网址末尾那串数字，例如 Dota 2 是 `https://store.steampowered.com/app/570/`，AppID 就是 `570`）。
3. 选择评测语言、时间范围，点击「开始抓取」。
4. 抓取 + AI 分析完成后，会弹出对话框询问是否生成推荐回复文案（可选导入自己的回复案例库）。
5. 报告和 Excel 会保存到程序所在目录的 `reports/` 文件夹。

## 二、配置说明（可选，但建议配置）

程序目录下有个 `config.local.json` 文件，用记事本打开可编辑：

```json
{
  "steam_web_api_key": "你的Steam Key",
  "deepseek_api_key": "你的DeepSeek Key",
  "llm_model": "deepseek-chat",
  "llm_base_url": "https://api.deepseek.com"
}
```

| 字段 | 作用 | 是否必须 |
|------|------|---------|
| `steam_web_api_key` | 抓取游戏更新记录（Patch Notes） | 建议配置，否则无法比对更新记录 |
| `deepseek_api_key` | 大模型语义判断 + 生成回复文案 | 建议配置，否则只能本地保守归类 |
| `llm_model` | 大模型名称 | 默认即可 |
| `llm_base_url` | 大模型接口地址 | 默认 DeepSeek，可换成任意 OpenAI 兼容接口 |

> 也可以在图形界面里直接填大模型的 Base URL / API Key / 模型名，无需编辑配置文件。

### 申请 Key

- **Steam Web API Key**：访问 https://steamcommunity.com/dev/apikey ，域名栏填你的任意主页（如 GitHub 主页），点击申请即可。
- **DeepSeek API Key**：访问 https://platform.deepseek.com ，注册后充值少量余额，在「API Keys」页面创建。

## 三、功能介绍

- **差评抓取**：抓取游戏历史差评（支持时间范围筛选）。
- **更新记录比对**：抓取 Patch Notes，用大模型判断差评问题是否已被修复。
- **四分类归类**：已解决 / 未解决 / 情绪化评论 / 待确认。
- **推荐回复生成**：参照回复案例库，为每条差评生成回复文案（可编辑）。
- **自定义案例库**：可导入自己的回复案例文件（xlsx/csv/md/txt/docx）。
- **报告导出**：HTML 报告（可筛选）+ Excel 表格（按类别分 sheet）。

## 四、常见问题

**Q：抓取很慢或超时？**
A：本工具访问 Steam 需要联网，网络不稳时会自动重试（代理/直连双通道）。若持续超时，请检查网络或代理设置。

**Q：提示"大模型账户余额不足"？**
A：DeepSeek 是预付费的，请到 platform.deepseek.com 充值。

**Q：数据会泄露吗？**
A：所有数据（API Key、抓取的差评）都保存在本地，不会上传。请勿把 `config.local.json` 分享给他人。

## 五、卸载

通过「控制面板 → 程序和功能」或「设置 → 应用」找到「Steam差评比对工具」卸载，或直接删除安装目录。
